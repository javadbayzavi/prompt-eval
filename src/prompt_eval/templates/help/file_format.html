Two ways to use it

Whole projectOne prompt
Export Project page → Export: every prompt of the project. Prompt → Settings → Export: that prompt alone, under its project's name.
Import Projects → Import: creates a new project with the file's name. Project page → Import prompts: adds the file's prompts to that project; its name and other prompts stay.

Both are the same file: a project file simply lists more prompts. Runs and reports are never in it. Importing an exported file gives back the same prompts, versions, scoring settings and test cases.
